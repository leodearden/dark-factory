1. **Designed against planned code, not landed code.** The lane's pick-then-dispatch split (P1-A1), 8528's bisect (P1-A3), and 8528's planned API (P2-A6) are all examples. It has now happened again, because 8528 landed without the suspect list.

3. **Identity keyed on something that does not survive.** The commit SHA (P1-A5), a content id that shifts with context lines (P2-A8), and task id versus request id.
4. **Promised bounds that cannot be met, or rules that contradict each other.** The suspect deadline versus no-mixing versus S1 versus the host count (P1-A6, P2-A5), and the storm limit versus the ordinary own-run outcome (P2-A9).

7. **Seams without a single owner, and premise numbers without a source.** "Whichever lands second" (P1-A15) and "8 of 11" (P1-A5).
