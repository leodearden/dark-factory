Onboard a software project — new or existing — as a dark-factory orchestrator target. Use whenever the user wants to 'factory-init' a repo, 'set up' or 'wire up' a project for the orchestrator, 'make this repo a dark-factory target', 'register a new project', or 'onboard <repo> into the factory' — or points at a directory and asks to get it ready for autonomous development, even if they don't say 'factory-init'. It confirms dark-factory is installed (installing it is out of scope), ensures a git repo, picks a hyphen-free project_id and a free escalation port, writes the per-project config, and registers the project with fused-memory reconciliation, then routes to review-briefing→review (existing code) or a goals discussion→/prd batch (greenfield), optionally adding a supervised systemd unit. NOT for: installing dark-factory itself (a separate skill), running the orchestrator (/orchestrate), writing a single PRD (/prd), creating a review briefing (/review-briefing), or unblocking a task (/unblock).
